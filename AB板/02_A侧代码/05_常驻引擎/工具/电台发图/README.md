2026-10-11 那一轮"常驻编码 + 电台发图"的工作副本。里面的东西分三类：

### 1. 部署到板子上跑的（**权威在别处**）

| 本目录 | 板上路径 | 权威 |
|---|---|---|
| `send_image.sh` | `/root/send_image.sh` | `工具/板端脚本/send_image.sh` |
| `glcenc_daemon.py` | `/root/glcenc_daemon.py` | **本目录**（`97dcd178`） |
| `glcenc_client.py` | — | 本目录 |
| `single_timing.sh` | `/root/single_timing.sh` | **本目录**（`fed32a44`） |

> `glcenc_daemon.py` 与 `single_timing.sh` 在 2026-10-15 的普查中确认：
> **板上跑的正本只在"快照"目录里**，本轮已提升到本目录 ⇒ 这里就是它们的权威。

### 2. 一次性 patch / 测试脚本（历史，留证据用）

`append_send2.py`、`fix_batchout.py`、`fix_bugs.py`、`mode_test.sh`、`v3_test.sh`

留在仓库是为了"当时到底改了什么"说得清 —— **不要重复运行**（补丁不幂等，会二次插入）。
