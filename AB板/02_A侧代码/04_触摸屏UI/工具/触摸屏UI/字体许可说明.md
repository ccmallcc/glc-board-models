# 字体许可说明（`ui_font.ttf`）

本目录的 `ui_font.ttf` 是 **Noto Sans SC** 的**子集**：只保留 `glc_ui.py` 里实际会画到屏上的
449 个字符（汉字 + 数字 + 拉丁字母 + 标点 + 空格），由 `make_ui_font.py` 用 fontTools 生成，
体积从 8,482,020 B 压到 85,436 B。

- 上游字体：**Noto Sans SC**（Google / Adobe）
- 许可：**SIL Open Font License 1.1（OFL-1.1）** —— 允许使用、修改、**再分发**（含子集化），
  要求保留本许可声明，且不得单独售卖字体本身。
- 本子集**未改名**发布为独立字体产品，仅作为本项目固件的一部分随附分发，符合 OFL 要求。

板子端只有 `/usr/share/fonts/truetype/dejavu/`（拉丁字形），**没有任何中文字形**；
`cv2.putText` 也只有 Hershey（纯 ASCII）。所以屏上写中文必须自带字体，这就是它的来源。

重新生成（在 Windows 上，用 `E:\fudanwei\envs\glc\python.exe`，需要 fontTools + Pillow）：

```bat
python make_ui_font.py --scan glc_ui.py
```

脚本会自动：① 从 `glc_ui.py` 的**字符串字面量**里扫出全部字符；② 从源字体做子集；
③ 逐字校验每个字符都渲染得出笔画（上次漏掉空格就是这么被发现的）。
