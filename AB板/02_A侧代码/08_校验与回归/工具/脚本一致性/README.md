# 脚本一致性普查工具（2026-10-15 一次性）

> 这**不是**日常要跑的工具链。日常只需要跑一个：
> ```bash
> python3 工具/校验_权威与板端.py
> ```
> 本目录是 2026-10-15 那次"全仓脚本漂移普查"用的脚本和原始数据，留档以便：
> ① 别人能复现本文档里的每个数字；② 半年后再查一次时有现成的家伙。

## 脚本

| 脚本 | 干什么 | 怎么跑 |
|---|---|---|
| `扫同名漂移.py` | 扫全仓**同名但 md5 不同**的文件组 | `python3 扫同名漂移.py [仓库路径]` |
| `按md5对板端.py` | 把仓库脚本与"板上在跑的"**按 md5 对号**（不按文件名） | 先抓 `证据/board_md5.txt`，再跑 |
| `找需提升的文件.py` | 找出"板端正本只在快照目录里"的文件 | 同上 |
| `生成权威清单.py` | 生成 `工具/权威清单.tsv`（md5 自动填 + 与板上核对） | 同上 |

抓板端 md5（供后三个脚本用）：

```bash
ssh -i ~/.ssh/id_board root@192.168.1.2 \
  'find /root -maxdepth 2 -type f \( -name "*.py" -o -name "*.sh" \) -exec md5sum {} \; ; md5sum /root/ui_font.ttf' \
  > 工具/脚本一致性/证据/board_md5.txt
```

## ★ 一个判据教训（写在这里免得下次再踩）

**按文件名对号会得出错误结论。** 实例：

```
板上 /root/radio_check.py            80c01a46  (113 行，含 +++ 修正)
仓库 工具/板端脚本/radio_check.py    d758a359  ( 84 行，无 +++ = 事故版)
```

按**名字**比 ⇒ 判"一致"；按 **md5** 比 ⇒ 发现是两个完全不同的脚本。
详见 `78_脚本权威性收口_…_20261015.md` §五.8。

**结论：判据要有判别力，且不能依赖会被绕过的东西（这里是文件名）。**
