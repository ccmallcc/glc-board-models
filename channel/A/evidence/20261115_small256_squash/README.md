## 两种口径的定义

import numpy as np

im = Image.open("ALB_0006.jpg").convert("RGB")
w, h = im.size

# 新口径 squash：整幅缩放到 256×256（两轴各自缩放）
new = im.resize((256, 256), Image.LANCZOS)

# 旧口径 fit：短边缩到 256，再中心裁 256×256

## 注意

- 两张 `*_256.png` 是**编码器输入的可视化**：由 `in0.ftmp`（float32、[-1,1]）按 `(t+1)×127.5` 反算并取整，
  与真正送进 NPU 的张量在 1 LSB 以内。
- 这个包**不涉及协议**：两个容器的帧格式、会话参数（`N=1`/`MODE=0`）、容器头完全一样。
