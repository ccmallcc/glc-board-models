## 建议的两步

**第一步：试水 3 帧（验"缺帧不拼"）**
1. 喂 `begin_3f.txt` → 再喂 `containers/000–002` 三帧 → 喂 `SESSION_END(ok=3)`；
2. **期望：不拼、不出 PNG**，并打印"缺帧 6 帧 ⇒ 不产出"。

**第二步：正式 9 帧**
1. 喂 `begin_9f.txt` → 依次喂 `000–008` → `SESSION_END(ok=9)`；
2. 期望输出 512×512 PNG。

## 说明

- 容器由板端 `send_image.sh --big --smooth9 --dry --batch` 一次跑出（A 端 9 块路径首次打通），
  `000.glc` 308 B / `001` 324 B / `002` 308 B / `003` 308 B / `004` 316 B / `005` 300 B / `006` 308 B / `007` 320 B / `008` 304 B；
- `crops/` 里的 PNG 是**编码输入**（读回时是 256×256 的编码前图像，不是解码结果），
  用它可以逐块算"解码块 vs 编码输入"的 PSNR，定位哪一块最难；
- 本包**不含 LIFT**：若你们想连带测 LIFT，我们可以另出一版（把 K 写进 BEGIN 尾部 2 字节，长度变 `4+2N+10`）。
