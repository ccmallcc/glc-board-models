| 5 | CUDA 编 → CPU 解 | NaN |
| 6 | CUDA 编 → CUDA **新进程**解 | **NaN** |

| 8 | 先验改 float64（CPU 编 / CPU 解） | 仍 26.61 dB，但 md5 `3880bedf…` 与 CPU 版不同 |

结论：**决定能否解码的不是先验的精度，是计算后端。** CPU 确定，CUDA 不确定。

## 4. 参考解码器

`decode.py`（本目录），只吃 `.glc`：

```bash
python decode.py IMG_0036.glc --img IMG_0036.jpg --out my_rec.png
```

依赖：GLC 官方参考实现 + `GLC_image.pth.tar`（md5 `41453cd3f45dcd505ef637d754df76cd`）。
**必须 CPU**，脚本对 `--device cuda` 直接报错退出。
